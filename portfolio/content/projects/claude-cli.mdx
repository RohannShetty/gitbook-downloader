## Problem Statement

Coding agents and CLI chats often struggle with massive codebases. They either overload the LLM context window with irrelevant file contents, run slow recursive searches, or fail to locate structural references across files.

## Approach

Claude CLI is a custom shell wrapper that integrates an AST parser and semantic indexer. It allows the CLI chat to query codebases intelligently, fetching only exact function and class signatures instead of dumping entire files.

## Technical Decisions

1. **Rust AST Parser**: Implemented a lightweight Rust-based AST parser for lightning-fast parsing of Python, TypeScript, and Go files.
2. **Local Vector Search**: Embedded a local SQLite vector extension to search code fragments semantically without relying on external cloud databases.
3. **Cooperative Caching**: Context blocks are cached locally and updated incrementally on git file changes.

## Results & Impact

- Context footprint reduced by 70%, saving token costs and reducing latency.
- Code search speeds dropped to under 100 milliseconds.
- Robust semantic search that accurately resolves dependencies across nested subdirectories.
