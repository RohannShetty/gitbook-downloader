## 🚀 Featured Open Source Projects

### 📦 [DocHarvest (GitBook Downloader)](https://github.com/RohannShetty/gitbook-downloader)
> **The Universal Documentation Harvester for LLMs, RAG & Offline Books**
- Automatically detects documentation platforms (**GitBook**, **Mintlify**, **Docusaurus**, **Nextra**, **ReadMe.io**, **VitePress**, **MkDocs**).
- Probes raw `.md` endpoints directly to extract pristine Markdown, cutting up to 89% of HTML boilerplate.
- Compiles 4-part output corpora: `book.md` (with TOC), `dataset.jsonl` (vector RAG), `llms.txt`, and pure-Python PDFs via `fpdf2`.
- Includes a desktop GUI (React + shadcn/ui) and native **FastMCP** server for Cursor and Claude Desktop.
- 🌐 [Live Showcase](https://rohannshetty.github.io/gitbook-downloader/) · 📦 [PyPI](https://pypi.org/project/gitbook-downloader/)
